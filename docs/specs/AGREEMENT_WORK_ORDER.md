### Article 3: Functional Scope & System Classification
* **3.1 System Classification (Strictly Internal Operations):** Classified strictly as an in-store, cloud-accessible **Enterprise Resource Planning (ERP) System** engineered solely for counter billing, inventory audit, vendor logistics, and operational governance. Explicitly excludes public e-commerce shopping storefronts, public booking carts, or customer-facing payment gateways.
* **3.2 Counter Booking & Settlement Lifecycle:** Multi-step customer counter order flow incorporating automated dynamic computation of rental tariffs, advance receipts, refundable security deposits, transit charges, and balance liabilities without manual calculation. Includes return inspection settlement and late-retention fee ledgers.
* **3.3 Rental Inventory Asset & Godown Warehouse Controls:** Centralized multi-parameter asset tracking incorporating unique piece identifiers, categorization, sizing, valuation, and physical godown rack/shelf location coordinates for immediate garment retrieval during peak footfall.
* **3.4 Fulfillment Scheduling & Event Delivery Alarms:** Visual matrix timeline providing multi-day availability visibility to prevent duplicate booking conflicts. Incorporates priority automated operational alert schedules prior to customer event deadlines for tailoring pickup and delivery readiness.
* **3.5 Vendor Care & Operations Management:** Integrated tracking registers managing external tailoring, alteration adjustments, and commercial dry-cleaning cycles, detailing vendor dispatch dates, expected turnaround, and customer fitting specifications.
* **3.6 Customer Digital Records & Communications:** Counter record generation delivering immediate digital verification slips, booking confirmations, and return settlement documentation directly via integrated communication protocols.
* **3.7 Cross-Device Responsive Accessibility:** Touch-optimized fluid interface engineered for mobile handheld devices, counter tablets, and administration desktop displays.
* **Technology & Infrastructure Standards:** Platform developed using high-performance web engineering standards, deployed over globally recognized, high-availability tier-1 cloud ecosystem partners (including industry-standard cloud platforms powering enterprise SaaS) ensuring high reliability, continuous uptime, and secure data persistence.
